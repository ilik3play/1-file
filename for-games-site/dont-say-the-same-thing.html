How to play
  1. Each round shows a category. The computer secretly picks 3 answers, usually the obvious ones.
  2. Type a real answer the computer didn't pick. Obvious answers score 100; rarer ones score up to 200, plus a time bonus.
  3. If you say the same thing as the computer, or the clock runs out, you lose a life. Answers it doesn't recognize don't count against you, so just try another.
  4. 10 rounds, 3 lives.
